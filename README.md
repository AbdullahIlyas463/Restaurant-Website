# 🍽️ Restaurant Website Demo

A modern, highly responsive, and visually engaging single-page restaurant website template. This project serves as a comprehensive frontend demo featuring a seamless user experience, smooth navigation, and direct integration links for delivery, social media, and customer contact.

🌟 **[Live Demo Link]** *(Replace this with your GitHub Pages or hosting URL)*

## ✨ Features

*   **Responsive Mobile Navigation:** Full mobile-friendly hamburger menu for seamless navigation across all device sizes.
*   **Smooth Scrolling:** Fluid transitions between sections for a premium, modern feel.
*   **Interactive Menu Categories:** Organized food and drink sections designed to let customers browse offerings effortlessly.
*   **Visual Gallery:** A dedicated photo grid showcasing the restaurant's best dishes and interior ambiance.
*   **Operational Details:** Clear presentation of restaurant opening hours to keep customers informed.
*   **Comprehensive Action Hub:** 
    *   **Direct Ordering:** Integrated links for **Foodpanda** and a **WhatsApp** chat ordering button.
    *   **Social & Local Proof:** Connected buttons for **Instagram**, **Facebook**, and a drop-pin link to **Google Maps**.
    *   **Instant Communication:** Click-to-action **Call Button** for quick phone reservations.

## 📂 Navigation & Structure

The landing page features the following key sections:
1.  **Home:** A hero section designed to capture visitors' attention immediately.
2.  **Menu:** Organized by food categories showcasing available dishes.
3.  **About:** A brief window into the restaurant’s culinary story and opening hours.
4.  **Gallery:** High-quality food photography layout.
5.  **Contact:** Form, location details, mapping links, and direct contact buttons.

## 🛠️ Built With

*   **HTML5:** Semantic architecture optimized for web accessibility.
*   **CSS3:** Flexbox, Grid layouts, custom animations, variables, and responsive media queries.
*   **JavaScript (ES6+):** Controls the mobile navigation toggle, smooth scroll behavior, and dynamic UI interactions.

## 🚀 Getting Started

Follow these steps to run a local copy of this project on your machine.

### Prerequisites

You only need a modern web browser and a text editor (such as VS Code) to open and modify this project.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Navigate into the project folder:
   ```bash
   cd restaurant-website-demo
   ```
3. Open `index.html` in your browser, or launch it using an extension like **Live Server** in VS Code.
